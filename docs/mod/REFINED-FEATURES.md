# Re:Fined and Nobody May Cry on the native KH2 port

**Keep NMC as the baseline. There is no identified Re:Fined dependency.** The best first addition is a controller-visible success or failure indication for task 57’s native autosave. Next come controller glyph selection and a clean screenshot option. Two often-cited reasons to install Re:Fined, faster title entry and a fix for suppressed voices, already have active NMC implementations. Retry, soft reset and multiple shortcuts are different cases. NMC exposes those switches but ships them off.

**The package has three layers.** OpenKH installs the core DLL, its config and Discord support. Panacea calls OnInit and OnFrame. The DLL locates game facilities, registers frame handlers and redirects individual game functions. Module DLLs register initialization/frame callbacks, can claim exclusive features, exclude core handlers and add new-game or Config entries. OpenKH also copies assets and patches named archive entries, lists, spawn points and event scripts. The package has no installed Lua script. D2380 tests for an *external* Garden randomizer Lua file. The normal build, Archipelago build and lite build register different subsets at D2016. The manifest selects five of the seven module binaries. ## Recommended options, in implementation order

Value is for the owner playing NMC with a PS5 pad on iPhone. Cost rates the *incremental* port work including validation. All new choices start off or inherit the existing NMC/port setting. Use C60’s controller menu and `kh_setting_set(name,value)` for live-safe settings. Persist startup/load-time settings in the C60 configuration and display when they take effect. C60 and S57 were in development during this study. Their interfaces and hook evidence below do not establish an integrated, tested release. ## Is it needed for the author’s intended experience?

**No requirement is evidenced for the pinned PC NMC package.** Its manifest installs KH2Tweaks_Refactor, KH2Moose, NeverlandFly, thirteen Tweaks INIs, Moose.ini and NMC’s command/shop tables.
