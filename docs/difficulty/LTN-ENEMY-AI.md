# Which enemies change on Less Than Nothing?

**83 enemy model files contain a difficulty check that changes an action, movement parameter, or wait.** They cover **82 distinct model names** and **59 distinct enemy BDX payloads**. The extra file is the US copy of Undead Pirate C. The Dusk skips retreat, the Gambler makes two conditional attacks reliable, and the Assault Rider drops long recovery waits and gains attack follow-ups. Some enemies simply spend less time idle. None of the matching models belongs to an objentry of type Boss (3) or Large Boss (12). Three Undead Pirates have B-prefixed filenames, and six enemy models occupy Hundred Acre Wood prop slots. An encounter can still use one of these actors as a boss. The finding is about the loaded actor model.

Across the entire tree, **97 files** matched, including 13 player/controller models and one area. MESSAGES.md lists five enemy files. Many additional comparisons are in action-table callbacks, beyond the trigger-only walk in bdxdis.py. The area also corrects that document's blanket “== 3” statement. Its comparison is with 2.

## How the VM reads the save

All RVAs below are relative to kh2fm.exe unless marked DLL. The PE image base is 0x140000000.

1. The script pushes character ID 1 and executes syscall table 0, entry 61, OpenKH's `trap_saveram_get_partram`. The VM shifts the opcode right six bits at 0x41c4b2, takes the table pointer, scales the next word by 16 at 0x41c4c8 and calls the descriptor at 0x41c4fa. The field-script table vector is at 0x753490. Its first pointer is 0x752e00. Entry 61 is **0x7531d0**, containing handler **0x41deb0** and flags **0x40000001** (one argument and one return).
2. Handler 0x41debb loads the party-record base **0x9abda0** and calls 0x3a14e0. Character remapping at 0x3e60c0 returns 1 for argument 1. The address calculation at 0x3a14f4–0x3a1500 is base + (mapped ID − 1) × 0x114. The handler converts the pointer to a script address via 0x4ad240 and tags the return slot at 0x41ded3.
3. BDX subtracts **0x58**. Thus 0x9abda0 − 0x58 = **0x9abd48** = 0x9a98b0 + 0x2498. Opcode 3, `push.d.pop 0`, resolves the VM address via 0x4ad270 at 0x41b9ef. The ordinary external-memory path loads a **dword** at 0x41c80f. BDX then masks it with **255** and returns. This explains why native cross-references to the difficulty getter missed enemy AI. Getter/setter 0x152350/0x152370 access the same underlying int32.
4. Reproducible example from the Dusk, 16 little-endian words starting at BDX PC 3440: `0000 0001 0000 000a 003d 0000 0058 0000 0046 0003 0000 0000 00ff 0000 0146 0089`. In order these push 1, call (0,61), push 88, subtract, dereference at offset zero, push 255, AND, and return. The following tables use decimal word PCs. File byte offset for **any** branch or call = member base + 0x10 + 2 × PC.

The NMC DLL installs its 114 extension syscalls in normally empty table 3 (vector slot 0x7534a8, DLL initialization 0x15120–0x15cd1). It supplies generic ReadByte (3,71, DLL 0x14080) and GetSaveram (3,92, DLL 0x14a60). Neither is needed by the observed helper. Its item and area consumers do use WriteByte (3,69, DLL 0x14040) and PlayerParamApply (3,80, DLL 0x14560). ## What a mode storing 1 gets

Every verified enemy comparison takes its Standard arm, including on world variants and repurposed enemy models. A new label or a different playable character cannot distinguish the mode to this helper. The controller writes zero to the seven item-command flags, so the positive HP/MP item divisor applies. The player scripts that implement the ability-based HP grant use 5 per counted ability instead of 2. The tt01 script skips PlayerParamApply(7). These outcomes assume the save actually contains 1 at the time of each check. The port has an optional forced-difficulty override after init and commit. [Port override](/home/user/work/khnmc-build/runtime/mod_difficulty.c:500)

With shipped settings, Standard also starts Sora at 25 AP from package 0 and gets 100% incoming and outgoing damage, full kill EXP, ordinary HP/MP/AP gains, start package 0, and ordinary boost caps of 240. LTN gets 200% incoming and 125% outgoing damage, 75% kill EXP (minimum 1), the index-3 AP rule, the additional start package, and boost caps of 120 HP/220 MP. The Standard ending/clear predicate uses the index-1 completion checks. These are independent readers of the stored level.
