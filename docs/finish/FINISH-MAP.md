# Where Roxas May Cry reaches

**The PC port passes the Great Maw.** On a fresh Standard save, staged into the campaign version of HB17_MS405, the controller entered with flag 0x105a clear. The game retired the mission, set the flag and moved to hb01 at frame 2429. A second run acknowledged the reward screens and reached world-map door 2, flag 4248 set, at frame 2934. Both NMC versions changed the vanilla room's result trigger from 7 to 16 while keeping that destination. The 1,000 Neoshadows encounter is a separate TWTNW sequence. [Input](run-finish/hb-clear.txt) · [28-step world-map result](private/run-finish/hb-world/summary.tsv) · [Flag and destination](private/run-finish/hb-clear/r01/run.out) · [Decoded room programs](run-finish/programs.tsv)

**There is no established point after which the PC campaign is simply absent.** Late world bosses, the armored and dragon sequence, story and Data Final Xemnas, the Garden and the Lingering Will mission have identifiable callers. Starting one with debug travel can omit its unlocks, party, inventory and previous result. The tests below separate entry, actual flag transitions, and a staged ending that wrote and reloaded a save. A normal-save completion percentage or universal first failure cannot be derived from those tests.

**What “complete PS2” means.** The supplied release is the rev6 V0.20 public alpha. Its Textscript describes the main story as playable and summons as disabled. Playnotes §4 describes the Engine Core fight and §5 calls Cavern of Remembrance and Lingering Will playable and unmodified. Changelog V0.20 adds three custom TWTNW fights, five replayable Traverse Town missions, English voices for the Absent Silhouettes and rearranged rewards. V0.19 names Final Xemnas, Luxord, Saïx, Larxene, Hades, Lexaeus and Vexen AI changes. These are release claims. File findings below come from KH2FM.NEW.ISO. ## Story and optional route map

IDs after a room are decimal program selectors unless prefixed with 0x. Item numbers are operands of the room's result list. A bonus selector in an MSN header is a separate source of rewards. For each row the program ledger lists the two versions' named missions, spawns, event IDs, flag and item operations and jump arguments. The file ledger gives the ISO byte offset and four file lengths. The member ledger isolates map, btl, evt, BDX, placement and timeline differences inside each BAR. Language or container alignment can change file bytes without changing any mission logic. ### Comparison coverage

The file ledger covers 772 candidate paths, including stock rooms, locale-adjusted missions, messages, progression tables and selected actors. The tool followed the discs' KH2.IDX and internal indices, expanded compressed members, preserved BAR duplicate-name occurrences and wrote the V0.20 files under private/ps2. The original disc supplied the four-way control. The installed PC comparison uses the pinned Git blob for each override. An unoverridden file could come from a clean extracted package or from the baked tree checked against the stock size index, distinguished in the clean_package column. A size-only fallback has weaker provenance. A dash identifies unavailable bytes. One out-of-bounds Shot member in PS2 P_EX102_MAGF.mset is excluded. The containing file remains indexed. The baked route tree matched all 254 pinned ARDs, 118 missions and 17 message overrides by Git blob ID.
